# Regras de SEO para posts do blog

- **Título:** Incluir palavra-chave principal (ex.: pace, running, calculator). Máximo ~60 caracteres. Atrativo para clique.
- **Meta description:** 150–155 caracteres. Incluir palavra-chave e call-to-action ou benefício. Não repetir o título.
- **Corpo:** Mínimo 300 palavras, ideal 400–600. Um único H1 (o título da página já é o H1). Use H2 para seções. Palavras-chave naturais (pace, corrida, tempo, ritmo, calculadora, 5k, 10k, meia maratona, maratona) sem keyword stuffing.
- **Tom:** Amigável, informativo, útil para corredores iniciantes e intermediários.
- **Formato:** Apenas Markdown: parágrafos, listas, **negrito**. Sem links externos inventados. Sem imagens no conteúdo.
